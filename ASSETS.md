# Brand assets

Place these files in the repo root for the landing hero and mark:

| File | Role |
|------|------|
| `hero.jpg` | Landing dual-profile neural lattice (circular crop) |
| `logo-or4cl3.png` | Primary Or4cl3 mark |

If missing, the landing still loads; the hero `<img>` will 404 until you add `hero.jpg`.

Source files were generated in the Or4cl3 brand kit session (logo + branded variants).

```bash
# After adding images locally:
git add hero.jpg logo-or4cl3.png
git commit -m "assets: Or4cl3 hero and logo"
git push
```
